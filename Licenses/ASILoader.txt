This project ships winmm.dll, which is a proxy build of Ultimate ASI Loader
(https://github.com/ThirteenAG/Ultimate-ASI-Loader) by ThirteenAG. The loader
initializes ASI plugins (see below) inside the game process, and is distributed
under the MIT License reproduced below.

    Ultimate ASI Loader
    Version 9.7.4 (Win32)
    Copyright (c) ThirteenAG

The ASI plugins that this project deploys (hta_chs.asi / hta_chs_dlc1.asi /
hta_chs_dlc2.asi, Render9Fix.asi, DLC1_MemFix.asi, DLC2_MemFix.asi) are placed
in the game's "update\" directory, which is where this loader picks up *.asi
files. Those plugins are original works of this project and are not part of
Ultimate ASI Loader.
